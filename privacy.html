HIERO MAX Uploader · 시행일 2026년 10월 17일

1. 이 앱이 하는 일

HIERO MAX Uploader(이하 「앱」)는 HIERO가 소유·운영하는 유튜브 채널에 영상을 업로드하고, 영상의 제목·설명·썸네일과 채널 게시물을 관리하기 위한 내부 도구입니다. 앱은 YouTube API Services를 사용합니다.

2. 접근하는 정보

앱은 Google OAuth 동의를 받은 채널에 대해 다음 범위로만 접근합니다.

  • youtube.upload — 영상 업로드
  • youtube — 해당 채널의 영상 목록·통계 조회, 제목·설명·썸네일 수정

앱은 다른 사람의 채널이나 시청자의 개인정보를 수집하지 않습니다.

3. 저장과 보관

OAuth 인증 토큰과 작업 기록은 운영자 컴퓨터에만 저장되며 외부 서버로 전송하지 않습니다. 채널 연결을 해제하면 해당 토큰은 즉시 사용할 수 없게 되고 운영자가 삭제합니다.

4. 제3자 제공

앱이 얻은 정보는 판매하거나 제3자와 공유하지 않습니다. 광고·분석 목적으로 사용하지 않습니다.

5. YouTube와 Google 정책

앱은 YouTube API Services를 사용하며, 이용 시 YouTube 서비스 약관이 적용됩니다. Google의 개인정보 처리 방식은 Google 개인정보처리방침을 따릅니다.

6. 접근 권한 철회

언제든지 Google 계정 보안 설정의 「서드 파티 액세스」에서 앱의 접근 권한을 철회할 수 있습니다.
